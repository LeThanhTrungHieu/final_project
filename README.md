   # GitHub Final Project: Simple Interest Calculator

   This project contains a Bash script that works as a simple interest calculator.
   The script asks the user for the principal amount, the rate of interest and the
   time period, then calculates the simple interest using the formula
   (principal x rate x time) / 100.
